# Testing — при работе с тестами

- **Тест — про поведение, не реализацию:** имя по поведению, мысленная мутация («упадёт ли, если код сломать?»), coverage — диагностика, не цель. Процедура — `.claude/docs/testing-guide.md`.
- **Мутация целит и в связи между слоями:** стаб обязан эмитить события, которые проверяет родитель; тест родителя ассертит наблюдаемое следствие, не факт вызова. Снёс биндинг — зелено = не покрыто.
- **Один вызов в N ветках — N мутаций**, считать места вызова в коде. «Вызван с аргументами» не видит лишнего и пропавшего вызова → счётчик до/после или ассерт на последний вызов.

Почему и примеры: `.claude/rules-detail/testing-files.md`
