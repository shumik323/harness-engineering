# Workflow — plan → work → review → ship

Порядок: разведка → grilling (`core:grilling`) → `/plan` с закрытыми развилками → work → verify → review → ship. `/compact` — по границе окна, не посреди задачи.

- **Нетривиальное → план до кода** по `/plan`. Пустая обязательная секция → из плана не выходим. Однострочный diff — без церемоний.
- **Spec — контракт:** сложное — критерии готовности до кода, примитив — типы + тест.
- **Минимум кода — стоп на первой ступени, которая держит:** не нужно → уже есть → stdlib → платформа → установленная зависимость → одна строка → код. Компонент дизайн-системы бьёт нативный; без «на будущее» и «заодно». Держит = проходит требование и тест; обработка ошибок и тесты под требование — не объём. Инспектор — `core:yagni-review`.
- **Новый срез / boundary → DoR-гейт до спеки и кода:** все входы получены или вслух названы отсутствующими; пустой → срез не берём. `.claude/docs/dor-gate.md`.
- **Объёмный док (>60 строк или >6KB) — агенту `scribe`.** Правки — точечный Edit; растущий док и лог — append через `scripts/log-append.sh`; файл >40KB — Bash in-place, не Edit.
- **Делегировать по умолчанию, самому — по причине**, вслух: агенту механика (`scout`), фон, чистое окно; себе контекст и решения. См. `.claude/docs/model-policy.md`, `.claude/docs/background-offload.md`.
- **Verify before ship:** изменение закрывается запускаемой проверкой (тест / сборка / линт); не можешь проверить — не отправляй.
- **Фича по макету → сверка с макетом перед «готово»** по замыслу; инструмент — `rules/lang/<lang>.md`.
- **Нетривиальное (многофайловое / поведение / CORE) → один свежий ревью-агент перед «готово».** Self-review не gate; мульти-агент — по явному запросу с ценой. Чеклист — `.claude/docs/REVIEW.md`. Есть AC-ID → первая секция — вердикт по каждому, по поведению, не по наличию теста; спеки нет — критерии не выдумывать. Фикс однострочный — сразу, иначе находки + план, ждать «да».
- **Релиз/тег → ревью леса:** смоук репы, дока ↔ реальность, приватное в git-истории.
- **Прецедент в коде сильнее правила:** получил не то — ищи источник в репо и правь его, не правило.
- **Build from failures:** инфраструктуру под несуществующую боль не строить.
- **Наблюдение по ходу — `/note`** (или append в `.claude/PENDING-NOTES.md`); разбор — `/end-session`.
- **Закрываю единицу → онбординг + «как проверить» + comprehension-gate:** закрыто, когда владелец подтвердил понимание. `.claude/docs/completion.md`.

Почему и примеры: `.claude/rules-detail/workflow.md`
