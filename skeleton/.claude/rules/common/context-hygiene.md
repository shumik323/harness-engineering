# Context Hygiene — гигиена контекстного окна

- **Источник истины — файлы, не история чата.** План, задачи, состояние — в файлах; читай их.
- **Вывод хука ушёл в `persisted-output` → прочитай файл целиком до первого действия;** preview ~2KB за контекст не считай. Регулярно не влезает — чини хук.
- **`/compact` проактивно на границе задачи;** в многослойной сборке — на границе каждого слоя, не копить >150k. Агент напоминает строкой, зовёт пользователь.
- **После тяжёлой MCP-фазы (макеты, браузер, скриншоты, дампы) — предложить `/compact`;** выжимку фактов в файл ДО compact.
- **JIT:** тяжёлые доки — Read по требованию. `@import` грузит на старте, для JIT не годится. Always-loaded держи тонким.
- **Подозрение, что правило выпало из окна — скажи и перечитай с диска.**
