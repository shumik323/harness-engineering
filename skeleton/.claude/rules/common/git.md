# Git — этикет коммитов

- **Коммит только по явному запросу** пользователя («commit»).
- **Переносы файлов — `mv`, не `git mv`:** индекс за владельцем.
- **Не коммитить в дефолтную ветку** — сначала ветка.
- **Readonly-зоны** (`READONLY_ZONES`) — только через build-команды; guard `block-zones.sh` блокирует (exit 2).
- **Не менять манифест зависимостей и лок-файл** без явного запроса.
- `gh` CLI для GitHub-операций (PR, issues).
- **`git merge --no-edit` всегда.**
- **Инструмент переноса не считает источник новее цели:** разница в обе стороны, по умолчанию версия рядом, перезапись — явным флагом, который отказывает, если у цели есть своё.
- **Резолв merge, одна ветка superset → `git checkout --ours` по всем конфликтным разом**, не пофайлово; вручную — только файлы с двусторонними авто-добавлениями. Маркеры правлю сам, `checkout`/`merge` — за владельцем.
